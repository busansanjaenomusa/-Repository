# 사직서 양식집 (HWP)

이음오피스(IeumOffice)로 만든 사유별 사직서 양식 8종입니다. 한글(.hwp)에서 바로 열어 빈칸을 채워 쓰면 됩니다.

| 파일 | 사유 | 실업급여 관련 참고 |
|---|---|---|
| 01_권고사직_사직서.hwp | 회사의 사직 권고 | 경영상 필요에 의한 권고사직 — 자발적 사직이 아님을 명시 |
| 02_개인사정_사직서.hwp | 일신상 사유(자진 퇴사) | 일반적으로 수급 대상 아님 |
| 03_이사통근곤란_사직서.hwp | 이사로 왕복 3시간 이상 통근 곤란 | 고용보험법 시행규칙 별표 2 |
| 04_가족간병_사직서.hwp | 부모·동거 친족 30일 이상 간호, 휴가·휴직 불허 | 고용보험법 시행규칙 별표 2 |
| 05_계약기간만료_사직서.hwp | 근로계약기간 만료 | 갱신 제안 거절 시 수급 제한 가능 — 갱신 여부 표시 |
| 06_본인질병_사직서.hwp | 본인 질병·부상, 업무 전환·휴직 불허 | 고용보험법 시행규칙 별표 2 |
| 07_임금체불_사직서.hwp | 임금 체불 | 고용보험법 시행규칙 별표 2, 근로기준법 제36조 |
| 08_임신출산육아_사직서.hwp | 임신·출산·육아, 휴가·휴직 불허 | 고용보험법 시행규칙 별표 2 |

- 공통: 인적사항 표, 사직 사유, 확인 사항, 날짜·서명란, 수신(대표이사 귀하).
- 03~08은 사유별 세부 내용 표와 첨부 서류 안내, 회사 확인란이 있습니다.
- 다시 만들기: `python3 make_forms.py <출력 폴더>` (이음오피스 CLI `~/.local/bin/ieumoffice` 필요)
